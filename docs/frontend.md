# Frontend UI

The Frontend is a modern Single Page Application (SPA) that provides the user interface for FlowForge.

## 1. Capabilities
*   **Kanban Board:** Drag-and-drop interface for task management.
*   **Analytics Dashboards:** Visual representations of project health and user productivity.
*   **Real-time Updates:** Integration with backend services for immediate feedback.
*   **Organization Management:** UI for inviting users and managing roles.

## 2. Technology Stack
*   **Framework:** Next.js / React.
*   **Styling:** TailwindCSS / Vanilla CSS.
*   **State Management:** React Query / Context API.
*   **Authentication:** JWT-based sessions stored in secure HTTP-only cookies.

## 3. Communication
*   **API Calls:** All requests are directed to the **API Gateway**.
*   **Routing:** Client-side routing for seamless navigation.
